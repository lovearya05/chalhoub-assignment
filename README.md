# Tiger Store — Expo / React Native assignment

A TypeScript shopping app based on [the supplied layout](layout/task.png). The original requirements are in [docs/ASSIGNMENT.md](docs/ASSIGNMENT.md); implementation decisions are recorded in [docs/PROGRESS.md](docs/PROGRESS.md).

Use Node 22.16 or newer. Install dependencies with `npm install`, then run `npm start` and open the QR code with a compatible Expo Go, or use an Android emulator / iOS Simulator. Run `npm run web` for a browser preview and `npm run typecheck` to check TypeScript.

Implementation proceeds through separate `step-1` through `step-6` branches. Each later branch contains the preceding stages. GitHub and Expo publishing setup will be documented with the finished app.
